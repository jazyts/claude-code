# aoiro — 個人事業主向け 青色申告 会計ソフト

売上の回数が少なく、あとは経費中心という個人事業主向けの、シンプルな複式簿記の会計ソフトです。
**税込経理**が前提です。Python の標準ライブラリだけで動き、データは手元の SQLite ファイル 1 つに保存します（外部に送信しません）。

## 使い方（Windows アプリ）

1. [最新版のページ](https://github.com/jazyts/claude-code/releases/latest)から **`aoiro.exe`** をダウンロードし、好きな場所（例: デスクトップや `C:\aoiro`）に置く
2. **`aoiro.exe` をダブルクリック** → 専用のウィンドウが開きます（Python のインストールは不要）
   - 初回に「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
   - 右クリック →「スタートにピン留め」や、デスクトップにショートカットを作ると便利です
3. 終わるときはウィンドウを閉じるか、右上の「終了」

- **更新**: 新しい版が出ると画面上部にお知らせが出ます。「内容を見て更新する」→「今すぐ更新する」で、自動でバックアップ・更新・再起動します
- **帳簿データ**: `C:\Users\（ユーザー名）\aoiro\books.sqlite3` に保存されます（アプリ本体とは別なので、更新してもそのまま）。以前の版のデータは初回起動時に自動で引き継ぎます（見つからない場合は「設定」→「以前の帳簿データを読み込む」）
- **バックアップ**: 起動時に1日1回、`aoiro\backups` と OneDrive の `aoiro\backups` に自動保存（30日分）
- **スマホで見る**: OneDrive の `aoiro` フォルダに「aoiro_サマリー.pdf」（売上・経費・所得・源泉徴収・未入金の請求書・最近の仕訳）を自動作成します。スマホの OneDrive アプリで開いてください（閲覧のみ）
- **Claude 連携**: 「設定」→「Claude Desktop に連携を設定する」

## 起動（Python から使う場合・開発者向け）

```sh
python3 -m aoiro app              # デスクトップアプリとして起動（起動.bat と同じ）
python3 -m aoiro serve --open     # 起動してブラウザを開く（すでに起動中なら画面を開くだけ）
python3 -m aoiro serve            # → http://127.0.0.1:8765/ をブラウザで開く
python3 -m aoiro --db 帳簿.sqlite3 serve --port 8000   # データファイルやポートを指定
python3 -m aoiro backup           # backups/ に日時付きでバックアップ
python3 -m aoiro verify           # 訂正削除履歴の改ざん・不整合チェック
python3 -m unittest discover -s tests   # テスト
```

Python 3.11 以上で動きます。インストールは不要です。

## はじめに行うこと

1. **設定**: 屋号・氏名、消費税の計算方法（一般課税 / 簡易課税 / 2割特例 / 免税）、青色申告特別控除額
2. **期首残高**: 1月1日時点の預金残高などを入力（元入金は自動計算）
3. **固定資産**: 10万円以上の備品などを登録しておくと、年末に減価償却仕訳を自動作成
4. ふだんは **仕訳入力** の「簡単入力」ボタン（売上計上・入金・経費・生活費の引出しなど）で入力

## Claude と連携（話しかけて仕訳・請求書）

Claude Desktop（パソコン版の Claude アプリ）と連携すると、Claude に頼むだけで帳簿を操作できます。

1. [Claude Desktop](https://claude.ai/download) をインストールしてログイン
2. アプリの「設定」→ **「Claude Desktop に連携を設定する」**を押す（Python 版は `Claude連携.bat`）。既存の設定は残り、バックアップも作られます
3. Claude Desktop を**完全に終了**（タスクトレイのアイコンを右クリック →「終了」）して起動し直す

頼めることの例:

- 「4月2日に文具店でコピー用紙1,100円、個人のカードで払った。仕訳して」
- 「この通帳の明細（画像）を仕訳にして。まず確認だけ」→ 内容を見てから「登録して」
- 「C.Port社に10月2日付で請求書を作って。8月分の調査業務 5.6時間、単価14,706円、源泉あり」
- 「C:\Users\…\請求書.pdf を読んで仕訳を入れて、PDFも保存して」
- 「今年の損益計算書を見せて」「源泉徴収の合計は？」「売掛金の残高は？」
- 「今年の税金はいくらになりそう？」「来年いつ何を払う？」
- 「No.12 の仕訳の科目を通信費に直して（理由: 科目誤り）」

しくみと安全策:

- Claude はこのパソコンの中の帳簿データ（`books.sqlite3`）を直接操作します。データがインターネット上に保存されることはありません（Claude との会話の内容は Claude に送られます）
- 登録・訂正・削除のときは、Claude Desktop が実行してよいか確認を求めます。Claude にも、登録前に内容を見せて確認するよう指示してあります
- 貸借の不一致・存在しない科目・締めた年への登録はエラーになり、何も登録されません。複数件はまとめて検証し、1件でも誤りがあれば全件登録しません
- 訂正・削除は理由が必須で、すべて訂正削除履歴に残ります（Claude による登録も履歴で区別できます）
- `aoiro.exe` を別の場所に移したら、もう一度「Claude Desktop に連携を設定する」を押してください

## 請求書

画面上部の「請求書」から使います。

- **請求書の作成**: 宛先・明細（日付・内容・数量・単位・単価・税率）を入れると（請求書番号は既定では表示せず、チェックで表示）、小計・税率ごとの消費税（切捨て）・源泉徴収（10.21%、100万円超の部分は20.42%）・ご請求金額を自動計算。A4の請求書を印刷・PDF保存できます（ブラウザの印刷で「PDFに保存」、「背景のグラフィック」にチェック）
- 保存すると**売上の仕訳を自動作成**: 売掛金（ご請求額）＋ 事業主貸（源泉所得税）／ 売上高（税込）。請求書を直すと仕訳も履歴付きで訂正、取消すと仕訳も削除されます
- **入金の登録**: 入金日・入金額・差し引かれた振込手数料を入れると、普通預金 ／ 売掛金 の仕訳を作成
- 発行者（肩書・氏名・住所・電話・登録番号）と振込先は次回以降の既定値として保存。「コピーして新規作成」で毎回の請求が簡単に
- **請求書PDFから仕訳**: 発行した・受け取った請求書のPDFから、日付・宛先・小計・消費税・源泉徴収・合計を読み取り、確認・修正してから仕訳を登録。PDFは証憑として保存されます（文字を選択できるPDFが対象。スキャン画像は手入力）
- **証憑の検索**: 保存した請求書・領収書を日付・金額（範囲）・取引先で検索（保存後の変更・削除は不可）。仕訳の画面から領収書などを添付することもできます
- **源泉徴収の集計**: 支払者ごとの収入金額と源泉徴収税額（確定申告書 第二表「所得の内訳」用）

## Excel・CSV からまとめて取込

画面上部の「取込」から、仕訳と期首残高を Excel（.xlsx）や CSV でまとめて登録できます。

1. 取込画面でテンプレートをダウンロードするか、画面の「Claude への依頼文」をコピーして、通帳明細・領収書・前年の決算書などと一緒に Claude に渡し、Excel を作ってもらう
2. ファイルを選んで「内容を確認」→ エラーや重複がないか確認 →「この内容で取り込む」

- 「仕訳」シート: `日付 / 伝票番号 / 取引先 / 摘要 / 借方科目 / 借方金額 / 貸方科目 / 貸方金額 / 税区分 / インボイス / メモ`。3行以上になる仕訳は同じ伝票番号を付けるか、2行目以降の日付を空欄にする
- 「期首残高」シート: `科目 / 金額`。元入金は自動計算（資産 − 負債）
- 科目名は「交際費」→接待交際費、「家賃」→地代家賃 などのよくある言い換えも認識します
- エラーが1件でもあれば何も登録しません。同じ日付・取引先・金額の仕訳や、取り込み済みのファイルは警告します
- 取り込んだ仕訳も通常の仕訳と同じく、訂正削除履歴が残ります

## 機能

| 区分 | 内容 |
|---|---|
| 帳簿 | 仕訳帳・総勘定元帳・合計残高試算表（印刷・CSV出力） |
| 決算書 | 青色申告決算書（一般用）の損益計算書・月別売上・減価償却費の計算・貸借対照表 |
| 消費税 | 税区分（10% / 8% / 非課税 / 対象外）とインボイス区分（適格・少額特例・経過措置）から納付税額を概算 |
| 税金予測 | 帳簿の所得と源泉徴収税額から、所得税（復興特別所得税込）・住民税・個人事業税・消費税の年税額と納付/還付額を予測。社会保険料・配偶者・扶養・医療費・ふるさと納税などの所得控除を入力でき、「あと10万円なら経費・共済・ふるさと納税のどれが得か」「青色申告特別控除65万/55万/10万の差」「翌年の納税スケジュール」も表示 |
| 決算整理 | 減価償却（定額法・事業割合）、家事按分、未払消費税の計上、年次繰越（元入金の自動計算） |
| 履歴 | 仕訳の訂正・削除は理由付きで全版を保存（削除は論理削除、仕訳番号は欠番として残る） |
| 検索 | 取引年月日・金額（範囲指定）・取引先・勘定科目・摘要を組み合わせて検索 |

## 青色申告の要件との対応

| 要件 | このソフトでの対応 |
|---|---|
| 正規の簿記（複式簿記）による記帳 | 貸借一致しない仕訳は登録不可 |
| 仕訳帳・総勘定元帳の備付け | 画面表示・印刷・CSV出力 |
| 貸借対照表・損益計算書の作成 | 青色申告決算書の様式に合わせて集計 |
| 優良な電子帳簿：訂正・削除の履歴の確保 | 全版を履歴テーブルに保存（DB トリガーで変更・削除を禁止、SHA-256 ハッシュチェーンで改ざん検知） |
| 優良な電子帳簿：帳簿間の相互関連性 | 総勘定元帳の各行から仕訳番号で仕訳へ遡れる |
| 優良な電子帳簿：検索機能 | 日付・金額の範囲指定、取引先、2項目以上の組合せ検索 |
| 優良な電子帳簿：システム関係書類の備付け | この README とソースコード |
| 締め後の改変防止 | 締めた年は仕訳・期首残高を変更不可（解除操作は変更ログに記録） |

### 注意（必ずお読みください）

- **65万円控除**を受けるには、このソフトで複式簿記の記帳をしたうえで、**e-Tax で申告**するか、**優良な電子帳簿の要件を満たして保存**する必要があります。
  このソフトは申告書の作成・送信はしません。決算書の数字を国税庁「確定申告書等作成コーナー」などに転記して e-Tax で提出する使い方を想定しています。
- 優良な電子帳簿として保存し過少申告加算税の軽減措置を受ける場合は、事前に届出書の提出が必要です。
- **電子取引のデータ保存**: メールやWebで受け取った請求書・領収書PDFは、「請求書PDFから仕訳」または仕訳画面の「証憑を添付」で保存すると、日付・金額・取引先で検索でき、変更・削除できない状態で保管されます。保存した PDF は帳簿データ（`books.sqlite3`）に含まれるので、バックアップを忘れずに。
- 消費税は**概算**です（割戻し計算。返還・貸倒れ・中間納付・特定収入などは非対応）。インボイスの経過措置割合や青色申告特別控除の要件は税制改正で変わることがあるため、申告前に国税庁の最新情報で確認してください。
- 青色事業専従者給与、各種引当金、棚卸資産の評価方法の届出などは扱っていません。
- 本ソフトは税務上の助言を行うものではありません。最終的な判断は税理士・税務署にご確認ください。

## 税込経理での仕訳例

| 取引 | 借方 | 貸方 |
|---|---|---|
| 請求書発行（275万円・税込） | 売掛金 2,750,000 | 売上高 2,750,000（課税売上10%） |
| 入金（振込手数料 440円差引） | 普通預金 2,749,560 / 支払手数料 440 | 売掛金 2,750,000 |
| 経費を個人のカードで支払 | 消耗品費 5,500（課税仕入10%） | 事業主借 5,500 |
| 生活費を事業用口座から | 事業主貸 300,000 | 普通預金 300,000 |
| 前年分の消費税を納付 | 租税公課（または未払計上済みなら未払金） | 普通預金 |

## データの保管

- 帳簿データはホームフォルダの `aoiro/books.sqlite3`（`--db` で変更可）です。**7年間（場合により10年）の保存義務**があります。自動バックアップに加えて、年に一度は別の媒体にも複製しておくと安心です。

## リリースの作り方（開発者向け）

`aoiro/__init__.py` の `__version__` と `CHANGELOG.md` を更新して main に取り込むと、GitHub Actions が Windows 上で `aoiro.exe` をビルド・動作確認し、リリースを作成します。アプリはこのリリースを見て更新を案内します。
- `.sqlite3` ファイルは Git に含めない設定（`.gitignore`）にしています。
