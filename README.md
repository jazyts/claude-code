# aoiro — 個人事業主向け 青色申告 会計ソフト

売上の回数が少なく、あとは経費中心という個人事業主向けの、シンプルな複式簿記の会計ソフトです。
**税込経理**が前提です。Python の標準ライブラリだけで動き、データは手元の SQLite ファイル 1 つに保存します（外部に送信しません）。

## 起動（Windows）

1. [Python](https://www.python.org/downloads/)（3.11 以上）をインストールする。途中の画面で **「Add python.exe to PATH」にチェック**を入れる
2. このページの緑の「Code」→「Download ZIP」でダウンロードし、右クリック→「すべて展開」
3. 展開したフォルダの **`起動.bat` をダブルクリック** → ブラウザで画面が開きます

- 使っている間は黒い画面を開いたままにしてください。閉じると終了します。
- 初回は「Windows によって PC が保護されました」と出ることがあります。「詳細情報」→「実行」を押してください。
- `起動.bat` を右クリック →「送る」→「デスクトップ（ショートカットを作成）」で、デスクトップから起動できます。
- 帳簿データは同じフォルダの `books.sqlite3` に保存されます。フォルダを移動するときはこのファイルも一緒に移してください。

## 起動（コマンド）

```sh
python3 -m aoiro serve --open     # 起動してブラウザを開く（すでに起動中なら画面を開くだけ）
python3 -m aoiro serve            # → http://127.0.0.1:8765/ をブラウザで開く
python3 -m aoiro --db 帳簿.sqlite3 serve --port 8000   # データファイルやポートを指定
python3 -m aoiro backup           # backups/ に日時付きでバックアップ
python3 -m aoiro verify           # 訂正削除履歴の改ざん・不整合チェック
python3 -m unittest discover -s tests   # テスト
```

Python 3.11 以上で動きます。インストールは不要です。

## はじめに行うこと

1. **設定**: 屋号・氏名、消費税の計算方法（一般課税 / 簡易課税 / 2割特例 / 免税）、青色申告特別控除額
2. **期首残高**: 1月1日時点の預金残高などを入力（元入金は自動計算）
3. **固定資産**: 10万円以上の備品などを登録しておくと、年末に減価償却仕訳を自動作成
4. ふだんは **仕訳入力** の「簡単入力」ボタン（売上計上・入金・経費・生活費の引出しなど）で入力

## 機能

| 区分 | 内容 |
|---|---|
| 帳簿 | 仕訳帳・総勘定元帳・合計残高試算表（印刷・CSV出力） |
| 決算書 | 青色申告決算書（一般用）の損益計算書・月別売上・減価償却費の計算・貸借対照表 |
| 消費税 | 税区分（10% / 8% / 非課税 / 対象外）とインボイス区分（適格・少額特例・経過措置）から納付税額を概算 |
| 決算整理 | 減価償却（定額法・事業割合）、家事按分、未払消費税の計上、年次繰越（元入金の自動計算） |
| 履歴 | 仕訳の訂正・削除は理由付きで全版を保存（削除は論理削除、仕訳番号は欠番として残る） |
| 検索 | 取引年月日・金額（範囲指定）・取引先・勘定科目・摘要を組み合わせて検索 |

## 青色申告の要件との対応

| 要件 | このソフトでの対応 |
|---|---|
| 正規の簿記（複式簿記）による記帳 | 貸借一致しない仕訳は登録不可 |
| 仕訳帳・総勘定元帳の備付け | 画面表示・印刷・CSV出力 |
| 貸借対照表・損益計算書の作成 | 青色申告決算書の様式に合わせて集計 |
| 優良な電子帳簿：訂正・削除の履歴の確保 | 全版を履歴テーブルに保存（DB トリガーで変更・削除を禁止、SHA-256 ハッシュチェーンで改ざん検知） |
| 優良な電子帳簿：帳簿間の相互関連性 | 総勘定元帳の各行から仕訳番号で仕訳へ遡れる |
| 優良な電子帳簿：検索機能 | 日付・金額の範囲指定、取引先、2項目以上の組合せ検索 |
| 優良な電子帳簿：システム関係書類の備付け | この README とソースコード |
| 締め後の改変防止 | 締めた年は仕訳・期首残高を変更不可（解除操作は変更ログに記録） |

### 注意（必ずお読みください）

- **65万円控除**を受けるには、このソフトで複式簿記の記帳をしたうえで、**e-Tax で申告**するか、**優良な電子帳簿の要件を満たして保存**する必要があります。
  このソフトは申告書の作成・送信はしません。決算書の数字を国税庁「確定申告書等作成コーナー」などに転記して e-Tax で提出する使い方を想定しています。
- 優良な電子帳簿として保存し過少申告加算税の軽減措置を受ける場合は、事前に届出書の提出が必要です。
- **電子取引のデータ保存**（メールやWebで受け取った請求書・領収書PDFの保存・検索）は、このソフトの対象外です。別途フォルダ管理等で対応してください。
- 消費税は**概算**です（割戻し計算。返還・貸倒れ・中間納付・特定収入などは非対応）。インボイスの経過措置割合や青色申告特別控除の要件は税制改正で変わることがあるため、申告前に国税庁の最新情報で確認してください。
- 青色事業専従者給与、各種引当金、棚卸資産の評価方法の届出などは扱っていません。
- 本ソフトは税務上の助言を行うものではありません。最終的な判断は税理士・税務署にご確認ください。

## 税込経理での仕訳例

| 取引 | 借方 | 貸方 |
|---|---|---|
| 請求書発行（275万円・税込） | 売掛金 2,750,000 | 売上高 2,750,000（課税売上10%） |
| 入金（振込手数料 440円差引） | 普通預金 2,749,560 / 支払手数料 440 | 売掛金 2,750,000 |
| 経費を個人のカードで支払 | 消耗品費 5,500（課税仕入10%） | 事業主借 5,500 |
| 生活費を事業用口座から | 事業主貸 300,000 | 普通預金 300,000 |
| 前年分の消費税を納付 | 租税公課（または未払計上済みなら未払金） | 普通預金 |

## データの保管

- 帳簿データは `books.sqlite3`（`--db` で変更可）です。**7年間（場合により10年）の保存義務**があるため、`backup` コマンドで定期的に別の場所へ複製してください。
- `.sqlite3` ファイルは Git に含めない設定（`.gitignore`）にしています。
